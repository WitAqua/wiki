# Rakuten Mini用のインストールガイド <Badge type="info" text="c330ae" />
::: warning
カスタムROMをフラッシュすると、アプリ、設定、システムファイルを含むデバイス上のすべてのデータが消去されます。必要なデータは必ず事前にバックアップを取るようにしてください。
:::

## 最新バージョンのストックROMを実行していることを確認

::: warning
当カスタムROMは、Rakuten Miniに配信された最新アップデート時点を基準に開発されています。
不具合を避けるため、初回導入時は必ず最終バージョンの `C330AE_9.0_RMN_JP_115_SS` に戻すようにしてください。

例えば、以下のような状態のまま導入すると失敗する可能性があるため、避けてください。
- ストックROMを古いバージョンのまま運用している場合
- AndroPlus 氏の `vendor_72_mod.img` を使用して crDroid 等の GSI を導入して運用している場合
:::

- 以下より、完全なストックROMをダウンロードしてください。
[Fastboot_c330ae_C330AE_9.0_RMN_JP_115_SS.zip](https://files.project2by2.jp/misc/c330ae/Fastboot_c330ae_C330AE_9.0_RMN_JP_115_SS.zip)
- 端末のUSBデバッグを有効にしてください。有効になっている場合は以下のように表示されます。
```
ABC12345XYZ device
```
- ダウンロードが終わりましたら、次のコマンドを実行し、ブートローダーに再起動します。
```bash
adb reboot bootloader
```

## Fastboot画面からストックROMを導入する

- PCでターミナルまたはコマンドプロンプトを開き、次のコマンドを実行します。
```bash
fastboot devices
```
- デバイスが認識されている場合、固有の識別子と「fastboot」という単語が表示されます。
```
ABC12345XYZ fastboot
```
- 次のコマンドを実行します。
```bash
fastboot update --skip-reboot Fastboot_c330ae_C330AE_9.0_RMN_JP_115_SS.zip
```
- 書き込みが終わりましたら、一度データの初期化を行い、再起動します。
```bash
fastboot -w
fastboot reboot
```
- 端末が再起動し、工場出荷時のAndroid 9が確実に起動することをご確認ください。
- 設定アプリを開き、下にスクロールして `端末情報` > 下部にある「ソフトウェアバージョン」が `C330AE_9.0_RMN_JP_115_SS` になっていればOKです。

## 書き込みに失敗した（起動しない）場合の対応方法

- デバイスが起動しない場合は、書き込みに失敗した可能性があります。そのときは`Volume Up`キーを長押ししてリカバリーに再起動します。
- 音量キーを使って`Reboot to bootloader`に合わせ、電源キーを押すと再度ブートローダー画面に戻ることができます。
- もう一度上記「Fastboot画面からストックROMを導入する」手順をやり直してください。

::: warning
ストックROMを導入した直後、必ず正常起動できていることを確認してください。
**正常起動が確認できていない場合は以下より先に進まないで下さい。復旧不可能になる可能性があります。**
:::

## リカバリーイメージの導入
- 端末のUSBデバッグを有効にしてください。有効になっている場合は以下のように表示されます。
```
ABC12345XYZ device
```
- 次のコマンドを実行し、ブートローダーに再起動します。
```bash
adb reboot bootloader
```
- PCでターミナルまたはコマンドプロンプトを開き、次のコマンドを実行します。
```bash
fastboot devices
```
- デバイスが認識されている場合、固有の識別子と「fastboot」という単語が表示されます。
```
ABC12345XYZ fastboot
```
- イメージファイル（`boot.img`、`dtbo.img`、`recovery.img`）がターミナル/コマンドプロンプトと同じディレクトリにあることを確認してください。
- 次のコマンドを実行します。
```bash
fastboot flash boot boot.img
fastboot flash dtbo dtbo.img
fastboot flash recovery recovery.img
```
- 3個のイメージをフラッシュしたら、音量キーを押して`Recovery mode`に合わせ、電源キーでリカバリーに再起動します。

## データフォーマットの実行
::: warning
データのフォーマットはすべてのユーザーファイルと設定を消去します。実行前にデータをバックアップしたことを確認してください。
:::
- **Factory reset** > **Format data/factory reset** を選択します。するとデータフォーマットが実行されます。

## ROMのインストール
- 左上の「←」ボタンを押してメインメニューに戻ります。
- `Apply Update` > `Apply from ADB` を選択します。
- PCで、ROMファイルが保存されているディレクトリに移動します。
- そのディレクトリでターミナルを開きます。
- sideloadコマンドを実行します。
```bash
adb sideload <filename>.zip
```
::: info
これには数分かかります。
:::
- インストールが完了したら、リカバリのメインメニューに戻ります。
- `Reboot system now`を選択します。
